# Laberinto de cristal

Juego de laberinto con bola de acero que se controla inclinando el móvil.

**Jugar:** https://isoslinux.github.io/laberinto/

- Lleva la bola al agujero con anillo.
- Desde el nivel 2 hay agujeros trampa: si caes, vuelves a la salida.
- Récord por nivel guardado en el navegador.
- Sin sensor: arrastra el dedo sobre el tablero o usa las flechas del teclado.
